# 수민 | 전기 설계 포트폴리오

[Ease Health](https://easehealth.com/) 스타일의 디자인 시스템(세이지/스카이 패널, 딥 포레스트 CTA, 세리프 헤드라인, 플로팅 카드 인터랙션)을 적용한 포트폴리오 사이트입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173` 을 엽니다.

## 구성

- Hero: 세이지 카피 패널 + 스카이 비주얼(CAD/CALC/FLOW 플로팅 카드)
- Stats / About / Strengths / Projects / Skills / Career / Contact
- 인터랙션: 스크롤 페이드인, 카드 플로트, 마퀴, 버튼 호버
